## 1.0.0 - 2026-10-13
### Added
- A visual editor for the Custom HTML block: in the WordPress editor, a page's text, links, images and background images are changed by clicking on them. Text is typed over in place, with bold, italic and link on a toolbar; an image is replaced from the Media Library and given alternative text; a button shows where it goes. Each change is written into the block's HTML where the change is, and the rest of the code is left as it was.

### Changed
- Rebuilt the plugin on the A8CSP plugin template for MCP clients such as Claude Design: pages are a single Custom HTML block stored as page content, in place of the per-page file sets; the MCP tools create a page and then read, change, or trash only the pages they created; two page templates, a full-width alignment for the Custom HTML block, and an AI Canvas card on the Settings → Connectors screen, with an Authorization header generator, are added. The file-based canvases and the rollback tool are removed.
